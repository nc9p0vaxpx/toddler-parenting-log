# 孕期到底要不要忌口?

> 更新时间：2026-09-11 (UTC+8)

孕期可以吃酱油、吃火锅，吃辣椒，可以吃羊肉、吃兔肉。

划重点：

怀孕后需要更加注意，饮食的安全性和营养性。一切以宝宝为中心！膳食适量、营养均衡、多样化。

觉得不错请点关注。
真正忌口的是这些
孕期不吃生肉，因为有被各种微生物感染的风险；

孕期不吃隔夜菜，特别是肉类熟食；

孕期不吃烟熏海鲜类及生鲜海产品；

孕期不吃生的蛤类以及蚌类；

孕期不吃没有煮熟的肉类和鸡蛋；

孕期不吃生鸡蛋，用生鸡蛋做的沙拉酱；

孕期不吃未经彻底加热的火腿、卤肉等熟食；

孕期不喝未经高温消毒的牛奶；

孕期不喝未经严格消毒的奶制品；

孕期不吃没有清洗过的水果蔬菜、蔬菜沙拉、不干净的拌菜；

孕期不吃含汞量比较多的鱼，包括鲨鱼、剑鱼、青花鱼、枪鱼和方头鱼等；

孕期不能食用生的鱼酱和肉酱。

当然，有些食物不需要在孕期忌口，但原则上还是要少吃一点。
比如下面这些要少吃
1、少喝咖啡

孕期可以喝咖啡，但是咖啡的量要限制，每天咖啡因的摄入量要小于 200mg。每天喝咖啡最多1杯。

注意除了咖啡，茶、奶茶等里面也含有咖啡因。

2、少吃含糖饮料、点心，以及高糖高油脂的食物（水果控量）

孕期体重的把控，影响着宝宝和你的健康，以及将来顺产的顺利，所以要注意上面这些内容。

尤其很多妈妈忽略了水果。吃水果健康，但是孕期要克制。（孕中晚期每天可以吃200～400g 水果）

比如像葡萄，里面含有大量的果糖和葡萄糖，很容易会吸收转化为脂肪储存起来，让体重增长加速。

3、炎热的夏天，也可以偶尔吃冰激凌，注意要少吃一点，解解馋就可以了！
孕期需要适当多吃哪些食物
1.新鲜蔬菜、适量的水果、及全谷类

蔬菜可以多吃。孕中晚期每天可以吃200～400g 水果，谷物200～250g。

2.乳制品

孕期坚持喝牛奶/低脂乳制品，能够提供好吸收的钙。孕中晚期每天喝300～500g 牛奶。每天口服钙片300～600mg。

3.优质蛋白质(如肉、鱼、蛋或干豆类）

孕中期后期要开始增加优质蛋白摄入，每天肉类总量大约200～250g。鱼类不仅可以提供优质蛋白，并且有益于宝宝发育。

（*每周2～3份汞含量极低的水产品，如虾、淡金枪鱼罐头、鲑鱼、鳕鱼和鲶鱼。或者吃1份低汞含量的鱼，如扁鲹、石斑鱼、大比目鱼、鲯鳅鱼和黄鳍金枪鱼。也可以食用金枪鱼排，但一周最多1次。）

4. 孕前三个月就要开始口服叶酸。每天补充0.4～0.8mg。

5.孕期容易贫血，要增加含铁丰富，而且吸收率较高的动物性食物,如瘦肉、血块、动物肝脏、牛羊肉等。必要时补充铁剂。

孕期饮食卫生注意事项：

1.制作食物前，一定要记得用肥皂和水好好洗干净双手；

2.确保肉类、蛋类都充分的煮熟；

3.切生熟食，砧板分开用；

4. 蔬菜水果一定要用流水充分洗干净后再食用；

5.吃东西前，洗干净双手，并注意餐具的清洁卫生；

6.一定要注意保障食物安全，没有污染，没有寄生虫。
